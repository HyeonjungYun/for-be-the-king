# 🗺️ DungeonKing 개발 로드맵

> **모드**: YOLO — 빠른 의사결정, 리스크 선(先)해소. 각 페이즈는 **하나의 검증 게이트**로 끝난다.
> **전제**: 인디/소규모 팀, UE 5.8, PC 전용. 야심작이므로 **기술·디자인 리스크를 앞단에서 죽이는 것**이 최우선.

## 0. 최우선 리스크 (모든 것을 게이팅함)

디자인 리뷰(2026-07-17)에서 도출 → **/brainstorm 개선 세션(2026-07-18)에서 디자인 리스크 확정**. 남은 건 기술 검증(R1/R6).

| ID | 리스크 | 종류 | 상태 |
|----|--------|------|------|
| **R1** | 심리스 넷코드 (Replication Graph + 서버권위 FoW) | 기술 | 🟡 **인원 12~16 하향 확정** — 실현성은 Phase 0-B 실측으로 최종 확정 |
| **R2** | 협동/배신 인센티브 붕괴 | 디자인 | ✅ **확정** — 솔로를 1급 경로로 재구성("고독한 길"), 협동은 선택적 고천장. §3 검증 |
| **R3** | 사망 페널티 강도 (4중 상실 = 이탈) | 디자인 | ✅ **확정** — 진행 이원화 + 부분사망(구역 바닥) + 스킬포인트 부분 보존 + 구출 수수료 |
| **R4** | 시체 루팅 규칙 | 디자인 | ✅ **확정** — 사망 시 가방 드랍 → **10분 루팅** → 소멸 (다크앤다커식) |
| **R5** | 기어 존-게이팅 (창고템 저구역 학살) | 디자인 | ✅ **폐기** — 부분사망으로 베테랑이 하위 구역에 안 돌아감 → 문제 소멸 |
| **R7** | 인구 4구역 쏠림 (부분사망 부작용) | 디자인 | ✅ **확정** — 시즌 & 프레스티지제(하이브리드 리셋)로 주기적 재분산 |
| **R6** | 풀루팅 치트 표면 (월핵/루트 ESP/속도핵) | 보안 | 🟡 Phase 2 서버권위 강제 |

## Phase 0 — 디자인 잠금 & 기술 검증 (약 2~4주)

**목표**: 코드 한 줄 크게 붓기 전에, 게임을 죽일 수 있는 질문에 답을 박는다.

### 0-A. 디자인 확정 (문서 작업) — ✅ 대부분 완료 (2026-07-18)
핵심 디자인 리스크는 /brainstorm 개선 세션에서 확정, `game-concept.md` §0/§3/§5에 반영됨:
- ✅ **[R4] 시체 루팅**: 사망 시 소지템이 맵에 **가방으로 드랍 → 10분간 타 플레이어 루팅 가능** → 이후 소멸 (경제 재순환)
- ✅ **[R3] 사망 페널티**: 진행 이원화 — 아이템만 상실(가방), 레벨은 **현재 구역 바닥까지만** 하락, 스킬포인트 부분 보존, **길드 구출 수수료(골드 싱크)**
- ✅ **[R2] 협동/배신**: 솔로를 1급 경로로("고독한 길": 솔로 전용 콘텐츠 + 자급자족 빌드), 협동은 선택적 고천장. 긴장 = "솔로-안전 vs 파티-고위험" 선택
- ✅ **[R5] 폐기**: 부분사망으로 무효화
- ✅ **[R7] 인구 분산**: 시즌 & 프레스티지제(하이브리드 리셋)

**남은 ❓ (밸런싱/라이브옵스 단계)**: "farm 후 배신" 익스플로잇 방지책(예: 협동 보너스를 공동 탈출 시 정산), 시즌 길이·리셋 범위, 각종 수치(구역 하락 폭·보존율·수수료), 배신자 낙인 가시성

**산출물**: ✅ 개정된 `game-concept.md` (완료) + 핵심 ADR 3~5개 (`/architecture-decision` — Architecture 단계)

### 0-B. 기술 스파이크 (버릴 코드, 검증만)
- **[R1] 넷코드 PoC**: UE5 Dedicated Server + `UReplicationGraph` 스페이셜 그리드. **더미 액터 16개 + 6스킬 난사** 상황에서 60Hz 서버틱 유지되는지 측정
- **[R1/R6] 서버권위 FoW PoC**: 시야 밖 액터를 *아예 리플리케이트 안 함* 검증(클라 마스킹 금지). 5~10Hz 시야 갱신 스태거링으로 프레임 예산 확인
- **목표 수치**: 16인 시뮬 부하에서 서버 프레임 < 16.6ms, 대역폭/커넥션 측정치 기록

**게이트**: 넷코드 PoC가 16인에서도 예산을 못 지키면 → **인원 추가 하향** 또는 **인스턴스형(비-심리스) 재설계**. 여기서 최종 결정한다.

관련 스킬: `/design-system` (핵심 시스템 GDD화), `/architecture-decision`, `/prototype` (기술 스파이크)

## Phase 1 — 코어 전투 프로토타입 (싱글플레이, 약 4~6주)

**목표**: "LoL 조작감 + 장비=스킬"이 **재미있는지** 네트워크 없이 먼저 증명.

- 탑다운 고정 카메라, WASD 이동, 마우스 우클릭 평타(대상 지정)
- 스킬 시전 3유형: 버프형(떼는 순간), 타겟형(홀드+좌클릭), 논타겟 범위기(본인만 범위 표시)
- **장비=스킬 슬롯 시스템** (GAS 기반 권장): 무기=평타/Shift/R, 모자=Q, 신발=E, 상하의=Z/X
- 1개 계열(예: 전사) 완성 스킬셋 + 더미 몬스터 파밍 루프
- 부시/시야는 로컬 근사로만 (넷코드는 Phase 2)

**게이트(PROCEED/PIVOT/KILL)**: 손맛 플레이테스트. "우클릭 평타 + 부위별 스킬"이 실제로 LoL스러운 쾌감을 주는가?
관련 스킬: `/prototype`, `/dev-story`, 에이전트: `unreal-specialist`, `ue-gas-specialist`

## Phase 2 — 멀티플레이어 파운데이션 (약 6~10주, 최대 리스크 구간)

**목표**: Phase 0 넷코드 PoC를 **프로덕션 품질**로. 서버권위 강제.

- Dedicated Server, 서버권위 이동/전투/히트판정(스킬샷 지연보상 포함)
- `UReplicationGraph` 스페이셜 그리드 본구현
- **[R6] 서버권위 FoW + 부시**: 숨은 액터/루트 미(未)리플리케이트, 스테일 위치 티어오프 처리
- **파티/노 프렌들리파이어/배신**: 전부 서버권위. 데미지 시점 파티 소속 조회, 배신 타임스탬프 서버 스탬프
- 치트 벡터 방어: 캐스트 창/쿨다운/좌표 서버 재검증
- **점진 부하 테스트**: 8인 → 12인 → 16인. 각 단계 프레임/대역폭 기록

**게이트**: 목표 인원(12~16, Phase 0-B 확정치) 실서버에서 목표 프레임/대역폭 충족.
관련 스킬: `/dev-story`, `/perf-profile`, `/security-audit`, 에이전트: `ue-replication-specialist`, `network-programmer`, `security-engineer`

## Phase 3 — 버티컬 슬라이스 (약 6~8주)

**목표**: 1개 존에서 **전체 게임 루프**를 관통 — 여기서 게임이 진짜 재밌는지 판정.

- 단일 존, 루프 전 구간: 베이스캠프 → 입장 → PvE 파밍 → 플레이어 조우(협동/경쟁/배신) → 탈출 → 결과
- **탈출 마킹 3분 수성전**: 석탑 채널링, 시전자 무방비, 근처 어그로 신호, 캐스터 DC/배신 엣지케이스
- **사망 처리 (확정안)**: 소지템 **가방 드랍 → 10분 루팅 창** + 부분사망(구역 바닥) + 구출 수수료. 가방 쟁탈전 긴장 검증
- **[R2/솔로] "고독한 길" 최소 검증**: 솔로 전용 루트/은신 이점 vs 파티 고천장의 대칭이 실제로 성립하는가
- 길드 마켓 최소 버전 (buy/sell 스프레드 = 골드 싱크/faucet 검증)
- **선택 긴장 실측**: 실제 플레이에서 솔로-안전 vs 파티-고위험 기대값, 협동 vs 배신 기대값 로깅

**게이트(PROCEED/PIVOT/KILL — Pre-Production→Production 전환)**: `/vertical-slice`. "솔로냐 파티냐"·"협동이냐 배신이냐" 긴장이 *실제로* 발생하는가? 사망 페널티가 스릴인가 이탈유발인가?
관련 스킬: `/vertical-slice`, `/playtest-report`, `/balance-check`

## Phase 4 — 프로덕션: 시스템 확장 (약 3~5개월)

**목표**: 검증된 슬라이스를 풀 게임으로 확장.

- 4개 계열(전사/마법사/암살자/성기사) 전 스킬셋 + 계열 세트 효과 + 성기사 "배신자 처단" 시그니처 + **솔로 자급자족 아키타입**
- 4개 존 + 레벨 구역제(Lv 상한)
- **"고독한 길" 솔로 콘텐츠**: 1인 전용 통로·고독의 사당·1인 금고/시련방 (파티 정예 콘텐츠와 가치 대등·종류 상이)
- **시즌 & 프레스티지 시스템**: 시즌 래더, 프레스티지 리셋, 하이브리드 롤오버(영구 보존 ↔ 시즌 리셋)
- 아이템/전리품 풀, 드롭 테이블, 스킬 강화(스킬포인트), **시체 가방 드랍/루팅**
- 경제 밸런싱: faucet/sink 정합(길드 가격, 창고 상한/유지비, 구출 수수료 등 골드 싱크)
- 세계관/베이스캠프/길드 NPC, UI/HUD(전장의 안개·파티·탈출·인벤)

관련 스킬: `/create-epics`→`/create-stories`→`/sprint-plan`→`/dev-story`, `/map-systems`, `/design-system`(계열별), `/ux-design`, `/team-combat`, `/team-ui`

## Phase 5 — 콘텐츠 · 밸런스 · 폴리시 (약 2~3개월)

- 몬스터/보스/구역 콘텐츠 채우기, 아이템 다양성
- 대규모 밸런스 패스 (`/balance-check`, `/review-all-gdds` 정합)
- 성능 최적화(Nanite/Lumen Lite, 12~16인 부하 하 60fps), 소크 테스트
- 오디오/VFX 폴리시, 접근성

관련 스킬: `/team-polish`, `/perf-profile`, `/soak-test`, `/balance-check`

## Phase 6 — 알파 → 베타 → 출시 (약 2~4개월)

- 클로즈드 알파(넷코드/치트/서버비용 실측) → 오픈 베타(경제·리텐션 실측)
- 안티치트 강화, 서버 인프라/오토스케일(단, 심리스 = 수직 확장 한계 유의)
- 출시 체크리스트, 스토어, 커뮤니티, 데이-원 패치 대비

관련 스킬: `/launch-checklist`, `/release-checklist`, `/security-audit`, `/day-one-patch`, `/patch-notes`
