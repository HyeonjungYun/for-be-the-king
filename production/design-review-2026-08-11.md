## 3. 렌즈별 핵심 발견

### network-programmer — 병목 진단이 틀렸다

> Room 4분할은 **층당 100명 문제에 적용 불가**합니다. "층당 100명"은 애초에 *하나의 Room 안* 인원입니다.

JobQueue도 마찬가지 — 설계상 한 Room은 **언제나 단일 스레드**입니다. 락을 없애는 것이지
O(N²) 팬아웃을 없애는 게 아닙니다.

```
100명 × 20Hz × 99명 팬아웃 = 초당 약 198,000회 Send() — 전부 한 스레드
```

**진짜 병목은 뮤텍스 경합이 아니라 컬링 없는 단일 스레드 팬아웃.**
문서의 완화책 두 개가 둘 다 엉뚱한 곳을 겨냥하고 있었습니다.

### performance-analyst — 같은 라벨, 정반대 용도

```
game-concept.md   "100명 최악 케이스"  →  일어나면 안 되는 시나리오 (반증용)
art-bible.md      "100명 최악 케이스"  →  견뎌야 하는 예산 기준 (드로우콜 여유 80%)
```

art-bible만 읽으면 "GPU 여유 80%"로 읽히지만, 그 여유는 **게임 디자인이 명시적으로 금지한 상태**를
기준으로 계산된 것이라 검증된 안전마진이 아닙니다.

추가로 **634 kbps 계산에 몬스터·전투 패킷·아이템 이벤트가 빠져 있습니다.** 플레이어 위치만 센 숫자입니다.

그리고 `production/roadmap.md`에 **폐기된 아키텍처 기준 게이트**(UE ReplicationGraph, 16인)가
그대로 남아 있어, 현재 아키텍처에 대한 서버 프레임 예산 게이트가 **어느 문서에도 없습니다.**

### economy-designer — 정의 하나가 티어 게이팅 전체를 결정한다

"드랍 시 레벨 초기화"의 범위가 정의되지 않았습니다. 창고 인출이 포함되지 않으면:

```
만렙 강화 → 성공 반출 → 창고에 레벨 보존
→ 죽어서 티어 강등 → 창고에서 예비 세트 → 즉시 원복
```

**"인구 자동 순환"이 거꾸로 작동합니다** — 예비 재고가 있는 베테랑에겐 강등이 안 일어나고,
재고가 없는 신규 유저에게만 강하게 작동합니다.

그리고 **골드 데드락**: 사망 시 전부 드랍인데 골드가 소지품이면,
구출이 필요한 그 플레이어가 구출 수수료를 이미 시체와 함께 떨궜습니다.

### game-designer — P1↔P5 충돌이 필러 표에서 빠져 있다

문서는 필러 충돌 두 개(P1↔P4, P3↔P1)를 스스로 짚었지만 **가장 위험한 조합을 놓쳤습니다.**

- 자기 티어 층에서는 파티 인원 제한이 없다
- 파티 분배에 시스템 페널티가 없다 (4명이면 처리량 4배)
- 탈출 게이지는 **1명만 남으면 계속 충전** → 정찰병 1명 세우고 3명이 경계하면
  문서가 "최고 난이도"로 지정한 60초 구간이 사실상 무력화된다

**결과: P5("안전한 축적은 없다")가 온전히 작동하는 대상은 솔로·듀오뿐입니다.**

또한 **탈출존 캠핑**이 지배 전략 후보입니다 — 게이지 알림이 공짜 타이밍 정보를 주므로,
던전에 안 들어가고 타워만 순회하는 것이 델빙보다 저비용·고빈도입니다.

### qa-lead — "재밌나?"는 pass/fail이 불가능하다

13주 개발의 유일한 검증 기준이 주관적 인상이었습니다. 텔레메트리 기반 지표로 대체했습니다.

**P4 ✅는 문서 자기 모순**이었습니다 — 484행은 "MVP에서 P4 검증됨"이라 하고,
397행은 "MVP는 클라이언트 FoW, **월핵 가능**"이라 합니다.
클라 FoW는 서버가 정보를 숨기지 않으므로 P4를 검증할 수 없습니다.

### narrative-director — 공백 4개가 한 질문에서 파생

몬스터 기원 · 왜 4층이 가장 위험한가 · 길드 동기 · 왕좌 도달의 실체 —
전부 **"왕국은 왜 무너졌나"** 하나가 미정이라 생긴 것이었습니다.

### systems-designer / level-designer / ai-programmer / unreal-specialist

| 렌즈 | 핵심 |
|---|---|
| systems-designer | 파티 인원 제한 공식이 **4티어 예시 1개로만** 정의. 티어 임계값 없음. **이동속도 상수 부재** |
| level-designer | "집 3~5개"가 확정/미정 동시 주장. "심리스"는 잘못된 라벨(허브 앤 스포크). MVP가 **어느 층인지** 미명시 |
| ai-programmer | **Pillar 1의 PvE 적용 여부 미정의** — 몬스터 AI 설계 블로킹 |
| unreal-specialist | 이동이 사실상 **클라이언트 권위**. 아트바이블 Lumen 결정 미적용 |

### 결정 16이 푼 것 — 상충하던 두 목표를 분리

이전 설계는 "10분 뒤 소멸" 하나로 정반대 목표를 동시에 떠받쳤습니다.

| | 원하는 회수율 |
|---|---|
| 리텐션 훅 "잃은 것 되찾기" | **높음** — 대부분 즉시 루팅돼야 재밌다 |
| 등급 아이템 인플레 억제 | **낮음** — 소멸이 유일한 싱크였다 |

**손잡이를 둘로 나눴습니다.**

```
PvP · 몬스터 사망  →  가방 드랍 · 10분 루팅 가능  →  회수 판타지
타이머 만료 사망    →  전량 소멸                   →  확정적 싱크
```

부수 효과로 **30분 타이머의 압박이 크게 올라갑니다** — 못 나가면 전부 증발입니다. P5 강화.

### 결정 18이 없앤 기술 리스크

| 항목 | 100명 | **30명** |
|---|---|---|
| 클라 대역폭 | 634 kbps | **186 kbps** |
| 초당 `Send()` | 198,000 | **17,400** |
| **거리 컬링(AOI)** | **필수** | **선택 — 최적화로 강등** |
| DummyClient 하네스 | 필수 | 있으면 좋음 |
| 서버 메모리 | 400명 → 256 MB | **120명 → 77 MB** |
| 드로우콜 (플레이어) | 200 | **60** |

**리뷰에서 "12주 일정에 없다"고 지적한 두 항목이 애초에 급하지 않게 되었습니다.**

```
280 m × 280 m = 78,400 m²
30명 ÷ 78,400 = 2,613 m² 당 1명
시야 반경 40 m = 5,027 m²
→ 균등 분포 시 동시 가시 ≈ 1.9명
```

**개활지의 희박함이 새 훅을 만들었습니다** — "싸우지 않는 길". 개활지 파밍은 수익이 낮은 대신
조우가 드뭅니다. **익스트랙션 장르에서 처음입니다.** Tarkov도 Dark and Darker도
들어가면 무조건 판돈이 걸립니다. Bartle Achiever 별점도 ★1 → ★2로 올랐습니다.

> **대가**: "탑다운에서 100명이 한 공간을 공유한다"는 훅이 사라졌습니다.
> Elevator Pitch와 Unique Hook을 다시 썼습니다. 30명도 익스트랙션 기준(6~18인)으로는
> 여전히 많지만, 숫자를 팔기는 어려워졌습니다. **게임 재미가 우선이라는 판단입니다.**

### 결정 19 — PvP 금지 존을 기각한 이유

제안된 "진입 포인트 주변 PvP 금지 존"은 채택하지 않았습니다.

1. **Anti-Pillar 정면 위반** — *"안전한 축적 수단을 만들지 않는다 — 던전 내 PvP 금지 구역"*
2. **악용됨** — 아이템을 잔뜩 들고 진입 포인트로 도망가면 무적. **사실상 두 번째 탈출구**가 되어
   "귀환로 매복"이라는 핵심 다이나믹이 죽음
3. **원래 문제를 안 품** — 신규 유저는 결국 존을 나가야 아이템을 얻고, 나가는 순간 똑같이 죽음.
   **죽는 시점을 60초 미룰 뿐**

원래 문제는 "안전"이 아니라 **"뭐가 일어났는지 모른다"** — 정보·학습 문제입니다.
**랜덤 진입 + 3초 무적**은 스폰킬만 차단하며, 스폰킬은 "안전한 축적"이 아니라
"시작조차 못 함"이므로 P5 위반이 아닙니다.

### 결정 4의 사실 정정

사용자가 "LoL은 클라에서 먼저 작동하고 서버에 동기화"라고 이해하고 있었으나,
**LoL은 완전한 서버 권위**입니다. 클라가 하는 것은 **예측(prediction)**이고
위치의 진실은 항상 서버가 갖습니다. 의도(반응성 확보)는 정확했고 라벨만 달랐습니다.

결정 3(이동속도 340)이 확정되면서 **속도 상한 검증이 구현 가능해졌습니다.**

### 결정 2·3·18이 열어준 계산 (최종)

```
층 크기   280 m × 280 m = 78,400 m²      (협곡 넓이 약 3.5배)
이동속도  340 cm/s = 3.4 m/s              (라이즈 기본값, 1 LoL 유닛 = 1 UE cm)
횡단      82초 · 대각선 116초 · 30분 = 횡단 22회

밀도:  30명 ÷ 78,400 m² = 2,613 m²/명
       시야 반경 40 m = 5,027 m²
       → 동시 가시 ≈ 1.9명

집 개수:  집당 5~8명 적정 (탑다운 판독 한계)  →  30 ÷ 6  =  약 5개
          MVP는 3개
집 간격:  280 ÷ √5 = 125 m ≈ 37초
```

**세션 시간 예산**

```
30분 = 1800초  −  탈출 게이지 60초  −  타워 귀환 ~60초  =  파밍 가능 ~1680초
집 하나 사이클 = 클리어 120~180초 + 이동 37초 = 157~217초
→ 집 5개 전부 도는 데 13~18분.  세션에 시간이 남는다.
```

**남는 시간이 개활지 루트의 존재 이유입니다.** 리스폰이 30분이라 같은 집을 두 번 털 수 없으므로,
남은 시간은 개활지 파밍 · PvP 조우 · 빈 집 추적으로 채워집니다.

> **"집 3~5개"가 다시 맞는 수치가 되었습니다.** 100명 기준으로는 집당 20~33명이 몰려
> 데스매치가 됐지만, 30명 기준으로는 집당 6명입니다. 폐기했던 수치가 되살아났습니다.
