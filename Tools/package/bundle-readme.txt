For be the King — 한 PC 실행 묶음
=====================================

자체 C++ IOCP 게임 서버 + 인증 서버 + MySQL + Unreal Engine 5.8 클라이언트를 한 폴더에 담았습니다.
설치 없이 이 PC 안에서만 돌아갑니다 (모두 127.0.0.1).

■ 실행
  1. Start.bat  — DB → 인증 서버 → 게임 서버 → 클라이언트 순서로 뜹니다 (처음엔 30초~1분)
  2. 로그인 화면에서 [가입] → 아이디 · 비밀번호 → 캐릭터 이름
  3. 베이스캠프: 길드장(위쪽 붉은 문 옆)에게 다가가 F → 1 "던전으로 가겠어" → [입장] → 진입 지점 클릭(또는 R = 무작위)
  4. 끝낼 때는 Stop.bat  (창만 닫으면 서버가 남습니다)

■ 상대가 필요하면
  AddBots.bat — 봇 30명이 같은 층(0층)에 들어옵니다. PvP 상대 · 부하 확인용
    · 봇마다 무작위 스킬 셋(무기 7종 × 빌드 5개 = 35개 중 하나)을 입고 들어옵니다
    · 빌드에 맞는 성격으로 움직입니다 — 결투형(플레이어를 노림) · 사냥형(몬스터 · 무리) · 약탈형(줍고 일찍 탈출) · 균형형
    · 무기 사거리를 지키고(활 · 스태프는 거리를 벌림), 평타 사이 옆걸음, 버프 → 약화 → 피해 → 돌진 순서로 스킬을 씁니다
    · 다치면 도망치고, 여럿에게 몰리면 피하고, 시야에서 사라진 적은 마지막 자리까지 쫓아 봅니다

■ 조작
  이동 WASD · 평타 우클릭(누르고 있기) · 스킬 Shift / Q / E / R / Z / X (조준 스킬은 키 → 좌클릭)
  F 대화 · 줍기 · Tab 소지품 · Esc 창 닫기

■ 필요한 것
  Windows 10/11 64비트 · DirectX 12 그래픽 카드
  "VCRUNTIME140.dll 이 없다" 가 뜨면: client\Engine\Extras\Redist\en-us\vc_redist.x64.exe 설치
  사용하는 포트: 3307(DB) · 8080(인증) · 7777(게임). 다른 프로그램이 쓰고 있으면 Start.bat 이 알려 줍니다

■ 문제가 생기면
  logs\ 폴더 — mysql.err · auth.log · gameserver.log
  client\S1\Saved\Logs\S1.log — 클라이언트

■ 알려진 한계
  · 다른 PC 에서 접속할 수 없습니다 (이 PC 안에서만)
  · 그래픽은 그레이박스, 공격 예고 · 투사체 표시는 임시 디버그 그리기입니다
  · 소리가 없습니다

■ 구성
  client\   Unreal Engine 5.8 클라이언트 (Win64 Development)
  server\   게임 서버 (C++ IOCP) · 부하 봇 · 게임 데이터 CSV
  auth\     인증 서버 (C# ASP.NET Core, .NET 런타임 포함)
  mysql\    MySQL 8.0 Community Server (GPL v2 — mysql\LICENSE) · 데이터는 이 폴더 안에만 저장
