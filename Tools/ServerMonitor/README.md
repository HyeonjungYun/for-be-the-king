# ServerMonitor — 서버 디버깅 툴 (C# WPF)

GameServer 의 **관리 포트**(`127.0.0.1:7790`, `FBTK_ADMIN_PORT`)에 붙어 서버 안을 실시간으로 본다.
서버가 꺼진 뒤에는 **지난 이벤트 로그**(`Logs/events/events-*.jsonl`)를 열어 같은 화면으로 본다.

```powershell
dotnet run --project Tools\ServerMonitor -c Release
# 또는 빌드한 exe
Tools\ServerMonitor\bin\Release\net10.0-windows\ServerMonitor.exe
```

요구: .NET 10 SDK (Windows). 서버 쪽 프로토콜은 [`PROTOCOL.md`](PROTOCOL.md).

## 연결

1. 서버를 띄운다. 부팅 때 `Server/Logs/admin.json` 에 포트 · 토큰 · pid 를 쓴다 (`FBTK_ADMIN_FILE` 로 위치 변경)
2. 앱을 켜면 저장소의 `Server\Logs\admin.json` 을 찾아 **정보 파일** 칸에 채운다 → **[연결]**
3. 서버가 여러 개면 **포트** · **토큰** 칸에 직접 쓴다 (비우면 정보 파일 값)

관리 포트는 **루프백 전용**이다. 같은 PC 에서만 붙는다. 토큰이 틀리면 서버가 끊는다.

## 화면

| 영역 | 무엇 |
|---|---|
| 왼쪽 **접속자** | 접속한 모든 인원 (사람 · 봇 구분 · 상태 · 방 · 체력). 이름 · id · 방 검색 · 봇 숨기기 |
| **로그** 탭 | 구조화 이벤트 로그. **태그 13 종** 토글 (접속 · 이동 · 전투 · 상태이상 · 아이템 · 창고 · 경제 · 파티 · 탈출 · 안티치트 · 몬스터 · DB 커밋 · 시스템) + 하위 종류 · 검색 · 오류만 |
| | **선택한 플레이어만** — 그 인원이 *행위자* 인 줄만, 또는 *관련 전부* (행위자 · 대상 · 계정) |
| **맵** 탭 | 방 하나의 현황 (5 Hz) — 층 지형 · 플레이어/봇 · 몬스터(상태 색) · 가방/상자 · 장판/투사체 · 사망 지점 · 순찰 길 · 타워 게이지. 휠 확대 · 끌어서 이동 · 클릭 선택 · 따라가기 · 시야 원 |
| **지표** 탭 | 동접 · Room 플러시 P95/P99/max · 커밋 메모리 · 송수신 · DB 큐 (10 초 통계. 점선 = 예산 P95 16.6 · P99 33 · max 100 ms · 512 MB — `Tools/verify/thresholds.json` 과 같은 값을 코드에 적어 두었다) |
| 오른쪽 **상세** | 선택한 플레이어 — 계정 · 위치 · 체력 · 런 골드 · 파티 · 시야 · 안티치트 점수 · 장비 · 스킬 칸 · 쿨다운 · 소지품 |
| 오른쪽 **관리 명령** | 강제 종료 (사유는 이벤트 로그에 남는다) · 정지 해제 (strike 도 지운다) · 전체 공지 (던전 HUD 8 초) |

## 태그는 어디서 오나

서버의 모든 로그 줄이 `Server/Data/event_tags.csv` 의 규칙(줄 머리 + 키워드)으로 태그 · 하위 종류를 받는다.
피해 · 상태이상은 서버가 구조화 이벤트로 직접 낸다. **새 로그 줄이 `시스템` 으로만 분류되면 CSV 에 규칙을 추가한다** (서버 재빌드 불필요 — 재부팅만).

## 명령줄 (자동 확인 · 증거 화면)

```
--info <admin.json>  --port N  --connect
--open <events.jsonl>
--tab log|map|metrics  --select <이름|id>  --tag combat,status
--shot <png> [--shot-after 초]     # 창을 PNG 로 남기고 끝낸다 (포그라운드 불필요)
```

## 알려진 한계

- **공지는 던전 HUD 에만 뜬다** — 클라가 `S_CHAT`(playerId 0)를 던전 알림으로 띄운다. 베이스캠프 · 로비 화면에는 아직 없다
- **강제 종료 사유 코드는 `KICK_REASON_NONE`** — `.proto` 에 관리자 사유가 없다. 사유 문장은 이벤트 로그에만 남는다
- 맵 되감기는 없다 — 지난 로그로 위치를 다시 그리지 않는다
- 지표 꺾은선은 앱을 연 뒤부터 쌓인다 (서버에 이력을 묻지 않는다)
- 3 층 등 지형 CSV 가 없는 층은 바탕 없이 오브젝트만 그린다
