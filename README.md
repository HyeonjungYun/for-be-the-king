# For be the King

**자체 C++ IOCP 게임 서버 + Unreal Engine 5.8 클라이언트.**
엔진 리플리케이션을 쓰지 않고 네트워크 계층을 바닥부터 직접 구현한 멀티플레이 프로젝트입니다.

탑다운 PvPvE 익스트랙션 게임 — 30명이 한 던전 층에 들어가 파밍하고, 제한시간 안에 탈출해야
장비를 들고 나옵니다. 죽으면 들고 있던 장비를 전부 떨어뜨립니다.

## 어떻게 개발했나

- **측정 → 원인 규명 → 수정 → 재측정.** 성능 · 안정성 작업은 바꾸기 전과 후를 같은 조건으로 재고 날짜순으로 기록하며 진행했습니다. 틀린 가설과 계측기 오류도 지우지 않고 남겼습니다.
- **서버 권위 · 데이터 중심.** 게임 규칙(스킬 · 몬스터 · 경제 · 탈출 · 시야)은 서버와 클라가 함께 읽는 CSV 에 두고, 판정은 모두 서버가 합니다.
- **2026-06 ~ 10-03** — 게임 서버 코어 · 넷코드 · DB 연동 · 지급 트랜잭션 · 계측 · 테스트와 CI 를 직접 작성했습니다. IOCP · 세션 · JobQueue 뼈대는 온라인 게임 서버 강의에서 배운 구조를 따랐고, 그 위의 계측 · 부하 봇 · 이동 검증 · 비동기 DB · 멱등 지급 · 테스트는 직접 설계했습니다. 이 기간 AI 코딩 에이전트(Claude Code)는 설계 문서 · 코드 리뷰 · 수정 제안에 쓰고, 적용은 읽고 판단한 뒤 손으로 했습니다.
- **2026-10-04 ~** — 게임 서버 코드 작성도 AI 에이전트에 맡겼습니다. 몬스터 AI · 길찾기 · 서버 벽 판정 · 스킬 엔진 확장 · 넷코드 보강 · 운영 기본기 리뷰 후속 · 동접 1만 확장이 이 시기 작업입니다. 저는 무엇을 만들지와 설계 결정 · 검증 기준(실측 · 테스트) · 변경 요약 검토를 맡았습니다.
- 클라이언트 게임플레이 · UI 코드는 처음부터 AI 초안을 검토해 반영했습니다.
- 커밋 메시지는 전 기간 AI 도구로 작성해 **모든 커밋에 `Co-Authored-By` 가 붙어 있습니다.** 그 표기는 메시지 작성 도구의 흔적이고, 코드를 누가 적용했는지는 위의 날짜 구분이 정확합니다.
